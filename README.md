# Sidenote

Take notes on lecture slides, one slide at a time. A Mac app.

This repository holds the builds: download the latest from [Releases](https://github.com/maxwernz/sidenote-releases/releases/latest). Open the disk image and drag Sidenote into Applications. From then on Sidenote offers new versions itself.

The app is not signed with an Apple developer certificate, so macOS blocks it the first time you open it. Open System Settings, go to Privacy & Security, and choose Open Anyway next to Sidenote.
